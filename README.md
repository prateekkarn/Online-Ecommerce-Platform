# Online Ecommerce Platform

A Java-based Online E-Commerce Platform developed using Object-Oriented Programming concepts and MySQL database connectivity through JDBC.

## 📌 Project Overview

The Online E-Commerce Platform is designed to simulate a basic e-commerce system where users can interact with products and place orders.

The project demonstrates core Java concepts such as:

- Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- Inheritance
- Collections and Generics
- Exception Handling
- JDBC and MySQL Database Connectivity

## 🚀 Features

- User management
- Buyer management
- Seller management
- Product management
- Order management
- MySQL database connectivity
- CRUD operations
- Console-based interaction

## 🛠️ Technologies Used

- **Java**
- **MySQL**
- **JDBC (Java Database Connectivity)**
- **Git & GitHub**
- **IntelliJ IDEA**
